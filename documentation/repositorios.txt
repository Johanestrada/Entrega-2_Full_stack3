## INSTRUCCIONES DE EJECUCIÓN

### Requisitos Previos
- Java 17 o superior
- Maven 3.8+
- Node.js 16+ (para frontend)
- Docker (opcional, para docker-compose)

### Opción 1: Ejecución Local (Maven)

1. Clonar repositorio:
   git clone https://github.com/Juan-Pablo26/Entrega-2_Full_stack3.git
   cd Entrega-2_Full_stack3
   git checkout develop

2. Instalar dependencias:
   ./mvnw clean install

3. Iniciar Eureka Server (primero):
   cd eureka-server
   ./mvnw spring-boot:run

4. En terminales separadas, iniciar microservicios:
   cd estudiante-service && ./mvnw spring-boot:run
   cd asistencia-service && ./mvnw spring-boot:run
   cd evaluacion-service && ./mvnw spring-boot:run
   cd bff-service && ./mvnw spring-boot:run

5. Iniciar Frontend (nueva terminal):
   cd frontend
   npm install
   npm run dev

6. Acceder a:
   - Frontend: http://localhost:4173
   - BFF Swagger: http://localhost:8084/swagger-ui.html
   - Eureka: http://localhost:8761

### Opción 2: Docker Compose
   docker-compose up

   Todos los servicios se iniciarán automáticamente en sus respectivos puertos.
